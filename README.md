## What I Work On

- **Robot learning & manipulation:** Visuomotor policy training via imitation 
  learning and RL, deployed on real 14-DoF hardware with sub-10ms inference 
  latency (CUDA, TensorRT). Built dual-arm teleoperation system for 
  demonstration data collection using MoveIt 2 and ros2_control.
- **Real-time systems:** Production-grade ROS2 middleware in C++20, lock-free 
  SPSC ring buffer, ABA-safe memory pool, POSIX SCHED_FIFO executor with CPU 
  affinity, p99 jitter ≤11µs across 95,951 samples.
- **Perception & SLAM:** Visual SLAM with semantic object-aware mapping 
  (ORB-SLAM3 + YOLOv8-seg), 3D object detection and tracking (89.9% mAP 
  KITTI), sensor fusion (camera, LiDAR, IMU).
- **Simulation & sim-to-real:** MuJoCo, Isaac Sim, Gazebo, environment 
  design, domain randomization, and sim-to-real transfer validation for 
  policy deployment.
- **ML pipelines:** Transformer-based classification pipelines (RoBERTa, 
  Longformer), TTS/voice cloning evaluation (Cantonese ASR benchmarking, 
  CER scoring, multi-model comparison at Vosyn).

I'm interested in collaborating on robot learning, perception systems, 
real-time robotics infrastructure, and embodied AI.
